# MIGraphX

Runs models on AMD GPUs through MIGraphX, AMD's graph compiler. Compiles the
whole model for the GPU, somewhat like [TensorRT](tensorrt.md) does for NVIDIA.

| | |
|---|---|
| Platforms | Linux |
| In the bundled binaries | **no** *(Linux not verified)* |
| Requirements | a supported AMD GPU, ROCm and MIGraphX, and an ONNX Runtime 1.22 build with MIGraphX |
| Method | `appendMIGraphXProvider([Map<String, String>? options])` |
| How options reach ONNX Runtime | **the plugin** fills ONNX Runtime's `OrtMIGraphXProviderOptions` struct from your map: ONNX Runtime 1.22 has no string-options function for MIGraphX |
| 1.22 source | `OrtMIGraphXProviderOptions` in [`onnxruntime_c_api.h`](https://github.com/syntax-syndicate/onnxruntime/blob/v1.22.0/include/onnxruntime/core/session/onnxruntime_c_api.h) |

## Usage

```dart
options
  ..appendMIGraphXProvider({
    'migraphx_fp16_enable': '1',
    'migraphx_save_compiled_model': '1',
    'migraphx_save_model_path': '$cacheDir/model.mxr',
  })
  ..appendCPUProvider(CPUFlags.useArena);
```

## Options

These are **all** the keys the plugin accepts; any other key throws
`ArgumentError` listing them. Omitted keys are zero, which is ONNX Runtime's
documented default for every field.

| Key | Values | Default | What it does |
|---|---|---|---|
| `device_id` | GPU index | `0` | Which GPU to use. |
| `migraphx_fp16_enable` | `1`/`0` | `0` | Allow FP16 precision. |
| `migraphx_int8_enable` | `1`/`0` | `0` | Allow INT8 precision. Needs a calibration table. |
| `migraphx_use_native_calibration_table` | `1`/`0` | `0` | Use a calibration table generated by MIGraphX. |
| `migraphx_int8_calibration_table_name` | file name | none | INT8 calibration table. |
| `migraphx_save_compiled_model` | `1`/`0` | `0` | Save the compiled model. |
| `migraphx_save_model_path` | path | none | Where to save it. |
| `migraphx_load_compiled_model` | `1`/`0` | `0` | Load a previously compiled model instead of compiling. |
| `migraphx_load_model_path` | path | none | Where to load it from. |
| `migraphx_exhaustive_tune` | `1`/`0` | `0` | Tune exhaustively while compiling: slower build, faster runs. |

On/off options also accept `true`/`false`.

## Notes

- With the bundled binaries the call throws an ONNX Runtime error saying the
  provider isn't available.
- If a later ONNX Runtime adds string options for MIGraphX, this provider can
  move to them and ONNX Runtime will validate the keys like for the others.
